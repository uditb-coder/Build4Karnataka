## 13. Slide / Page Design Guidance

### Layout Rules
- One core message per page
- Maximum 3 visuals per page
- Use short interpretation text below every chart
- Avoid long narrative paragraphs
- Keep institutional descriptions to one page total

### Visual Style
- Use brand colors consistently
- Use one font family for headings and one for body text
- Use icons for attendance, outcomes, feedback, and projects
- Highlight key figures using metric cards

### Interpretation Rule
Every graph must be followed by:
- what the graph shows
- why it matters
- what action it suggests
